# Contributing

Thanks for helping improve Maintainer Cron Kit.

## Development Setup

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e .
python -m unittest
```

## Contribution Guidelines

- Keep the default workflow read-only.
- Avoid adding required third-party services.
- Do not commit secrets, personal data, private repository data, or generated credentials.
- Prefer small, testable pull requests.
- Include a short before/after example for user-facing output changes.

## Good First Issues

- More release-note grouping strategies.
- Better stale-thread heuristics.
- GitHub Enterprise URL support.
- Optional JSON output.
