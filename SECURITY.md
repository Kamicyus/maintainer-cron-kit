# Security Policy

## Supported Versions

Only the latest released version is supported while the project is in alpha.

## Reporting a Vulnerability

Please report security concerns through GitHub private vulnerability reporting if it is enabled for the repository. If it is not enabled, open a minimal issue that does not disclose exploit details and ask for a private contact path.

Do not include secrets, private repository data, customer data, or third-party confidential material in public issues.

## Authorization Boundary

Maintainer Cron Kit is for repositories you own, maintain, or have explicit permission to administer. Do not use it to scan, test, or summarize repositories that you are not authorized to review.
